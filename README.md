# Candela

Teste biblice pentru pregătire, după traducerea Cornilescu: 1 Samuel și 2 Samuel, cu întrebări pe categorii de vârstă, ca la examen.

Aceasta este versiunea 2 (ramura `v2`), în lucru. Planul: `docs/v2-plan.md`.

```
npm install
npm run dev     # http://localhost:4321
npm run build
```

Astro + Preact, Firebase (Authentication, Firestore), găzduit pe Vercel.
